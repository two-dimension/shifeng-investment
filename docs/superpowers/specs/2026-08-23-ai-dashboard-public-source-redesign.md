# AI 投资看板公开数据源整体重构设计

日期：2026-08-23

## 1. 目标

把 AI 投资看板从“展示飞书中已有数据”重构为“主动读取公开网络、保留数据口径、计算投资者可理解的变化、持续更新并对失败显式降级”的研究看板。

飞书从运行时、刷新接口、页面来源状态和回退链路中完全退出。历史飞书导出只用于迁移期测试夹具，不得继续生成生产快照。

最终看板包含六条相互独立但共享来源治理的链路：

1. ARR、估值与 P/ARR；
2. OpenRouter 周 Token；
3. 最新模型、视频模型与 Coding Plan 定价及涨降价事件；
4. 国内外 CSP、模型厂商融资与债务；
5. 厂商第一方模型卡 Benchmark，以及独立的 Artificial Analysis 参考图；
6. 算力租赁价格。

## 2. 全局数据原则

### 2.1 来源优先级

每条记录必须保存原始 URL、来源名称、抓取时间、数据日期、口径说明和来源类型。

来源优先级固定为：

1. 公司官网、官方文档、官方模型卡、官方新闻稿或投资者关系页面；
2. 监管披露、交易所公告、债券募集文件和公司控制的官方代码/模型组织；
3. Yipit 等明确标注的估算来源；
4. 仅在独立参考板块中使用的指定第三方来源。

媒体转述、搜索摘要和聚合榜单只能帮助发现原始材料，不能作为最终数值来源。无法回到允许来源的数字不进入快照。

### 2.2 口径与悬浮说明

所有 KPI、图表点和表格数值均可查看口径。通用字段为：

- `sourceLabel`：面向用户的来源名；
- `sourceUrl`：原始页面；
- `sourceKind`：`official`、`filing`、`estimate` 或 `named-third-party`；
- `asOf`：数据对应日期；
- `retrievedAt`：抓取日期；
- `methodology`：统计或计算口径；
- `commentary`：事件背景和投资解释；
- `stale`：是否超过该板块新鲜度窗口。

页面在数值标题旁显示问号圆标。悬浮内容至少包含“数据口径、数据来源、数据日期”；图表点还显示对应点评和原始链接。

### 2.3 失败、回退与真实性

- 单一来源失败时只保留该来源上一次成功记录，并标记过期；
- 从未成功的来源显示“暂不可用”，不得注入样例数字；
- 估算值与官方披露值不得合并成一个数字；
- 未披露的 Benchmark 显示“未披露”，不得显示 0；
- 抓取、解析、标准化和写入分离，只有完整通过校验的切片才能原子替换 last-good；
- 页面不得把部分来源成功描述成“全部数据最新”。

## 3. 统一数据与刷新架构

服务端维护受控来源注册表。每个注册项声明规范实体名、允许域名、官方入口、数据类型、解析器、新鲜度和更新频率。运行时不接受前端传入任意 URL。

共享安全客户端负责：

- HTTPS 和允许域名校验；
- 重定向后域名再次校验；
- 超时、响应体上限和内容类型校验；
- HTML、JSON、Markdown 与 PDF 的读取；
- 抓取审计信息；
- 并发限制与失败隔离。

`AiDashboardSnapshot` 升级到 schema v2，来源状态不再包含 `feishu`，而是按数据切片记录：

- `growth`；
- `openRouter`；
- `pricing`；
- `capital`；
- `benchmarks`；
- `artificialAnalysis`；
- `compute`。

刷新 API 继续使用 `POST /api/ai-dashboard/refresh`，允许上述切片名。默认手动刷新全部切片；进入高成本页签时只刷新对应切片。定时刷新由服务端执行，失败不影响其他切片。

## 4. ARR、估值与 P/ARR

### 4.1 Anthropic 口径

Anthropic 当前的 Yipit ARR 记录明确标记：

- `sourceKind: "estimate"`；
- `sourceLabel: "Yipit"`；
- `methodology` 说明其为 Yipit 估算；
- 单位和币种不得在换算时丢失。

另行查找 Anthropic 官方披露或公司高管公开披露的 ARR。官方值与 Yipit 值并列展示，并分别带口径、日期和来源；没有可核对的官方原始材料时不采用媒体数字。

### 4.2 指标和图表

- 删除“三月斜率”作为核心 KPI；
- 每个实测月份计算环比绝对增量 `momAbsolute`；
- 数据连续且前月非零时同时计算环比百分比 `momPercent`；
- Anthropic 与 OpenAI 的 ARR 实测历史绘制在同一张折线图；
- 估算/预测使用不同线型，不参与官方口径或 P/ARR 的错误混算；
- 悬浮显示公司、ARR、环比增量、环比百分比、口径和点评。

### 4.3 P/ARR

- P/ARR 必须包含 OpenAI；
- 使用估值日之前最近一条同口径 ARR 匹配；
- 保存完整估值和 P/ARR 历史，不限最近三个月；
- 同一图表显示 Anthropic 与 OpenAI 的历史倍数；
- 每个点显示估值事件、ARR 匹配日期、计算式与点评。

## 5. OpenRouter 周 Token

OpenRouter 只用于 Token 流量，不用于 Benchmark。

- 聚合最近两个完整 UTC 七日窗口；
- 核心 KPI 为 `weekOverWeekAbsolute = 本周 Token - 上周 Token`；
- 同时计算 `weekOverWeekPercent`，但前周为零时留空；
- 绝对周 Token 作为辅助上下文；
- 历史图展示每周总量和周增量；
- Top 模型表保留，但不得用 Token 流量暗示模型质量；
- 无 Data API 授权时，公开 Top 10 可以展示，平台周环比必须明确不可用。

## 6. 最新模型价格、视频 API、Coding Plan 与价格新闻

### 6.1 厂商范围

文本模型价格至少跟踪：OpenAI、Anthropic、Gemini、智谱、MiniMax、Kimi、DeepSeek、Mimo、Qwen；可增加 Meta、Tencent 和 xAI，但不得减少前述九家。

每家只展示当前最新一代正式可用的通用模型 SKU。旗舰、平衡和轻量型号属于同一代时可并列；旧代模型从主图移除，但历史价格保留用于涨降价事件。

### 6.2 文本 API 价格

统一保留币种、每百万 Token 单价、上下文档位、标准/批处理/区域等计费层级。标准字段包括输入、缓存输入、缓存写入和输出；官方没有某一项时留空。

价格图默认展示各厂商最新一代标准公开价，不把 Batch、区域溢价或长上下文价格混进同一柱。其他档位放在明细和悬浮说明中。

### 6.3 涨价与降价新闻

价格变化由同一官方 SKU 的历史快照计算，官方公告补充事件解释。事件字段包括厂商、模型、价格维度、旧价、新价、绝对变化、百分比、公告日期和官方链接。页面在模型价格旁展示最近事件流。

### 6.4 视频 API

视频价格从官方 API 文档读取，优先覆盖 Kling 与 Seedance，并纳入其他存在可验证公开 API 定价的主流视频模型。保存模型、模式、分辨率、时长、是否含音频、币种和价格单位；统一换算价格时必须保留原始计费单位。

Sora 仅在存在当前可验证的公开 API 及定价时展示，不能沿用过期条目。

### 6.5 Coding Plan

从官方订阅或产品价格页读取月付、年付折算、额度、模型范围、超量计费和地区限制。没有公开固定价格的计划显示“询价”或“未公开”，不得猜测。

## 7. 融资与债务融资

覆盖国内外 CSP、基础模型厂商和重要 AI 基础设施企业。首批实体至少包括 OpenAI、Anthropic、Google、Microsoft、Amazon、Meta、xAI、CoreWeave、Alibaba、Tencent、Baidu、智谱、MiniMax、Moonshot、DeepSeek 和小米。

每条融资记录保存：

- 公司和国家/地区；
- 公告日期、交割日期和到期日；
- 股权、贷款、债券、可转债、信贷额度或其他工具；
- 规模、币种和可比美元金额；
- 利率、票息、基准利率与利差；
- 期限、投资者/贷款方和资金用途；
- 官方公告、监管披露或交易所文件；
- 口径与点评。

聚合层计算公司累计融资、最近十二个月融资、融资次数、债务加权平均票息（仅对口径可比的固定票息债务）和融资时间线。未知利率留空，不以行业均值代替。

## 8. Benchmark 与 Artificial Analysis

### 8.1 厂商第一方 Benchmark

厂商模型卡 Benchmark 遵循 `docs/superpowers/specs/2026-08-23-official-model-card-benchmarks-design.md`：

- 每家只展示最新旗舰通用文本模型；
- 分数只能来自该厂商第一方官网、模型卡、系统卡或技术报告；
- 不使用 OpenRouter Benchmark API、飞书 Benchmark 或第三方榜单补齐；
- 官网未披露留空，旧模型不得补位；
- test name、版本、split、score name、agent/harness、effort、shots/pass@k 和工具策略决定可比性；
- 新模型发布后即替换旧模型，即使新模型未公布任何分数；
- 不存在 Fable/Mythos 排除规则；任何进入允许数据集且满足可比性的模型都可成为分项冠军。

### 8.2 Artificial Analysis 独立参考图

Artificial Analysis Intelligence Index 是唯一明确允许的第三方能力参考板块。它与官方模型卡矩阵物理和语义分离：

- 不写入官方模型卡分数；
- 不参与官方 Benchmark 冠军；
- 明确标记 `named-third-party`；
- 页面注明其测试口径、数据日期和链接；
- 若来源不允许稳定自动读取，则保留 last-good 并显示更新状态。

### 8.3 单任务 Token 与成本

独立图展示同一任务口径下的输出质量、输入 Token、输出 Token 和估算成本。成本按记录对应日期的官方 API 价格计算，展示计算式。不同任务、不同 agent/harness 或不同测试版本不得直接排行；缺少 Token 明细的模型留空。

## 9. 算力租赁

只读取云厂商或 GPU 平台官方价格页/API。保存平台、GPU、实例规格、区域、计费模式、按需价、抢占/Spot 价、币种、每小时归一价、数据日期和官方链接。

聚合层计算同平台同实例的绝对和百分比涨跌；跨区域或不同实例规格不得直接当作同一价格序列。页面显示最新横向对比、历史趋势、更新时间和过期提示。

## 10. 页面结构

主页签保持：总览、ARR & 估值、OpenRouter、模型价格、Benchmark、算力租赁、融资。

- 总览只放能解释变化的 KPI：ARR 月环比、OpenRouter 周环比、最近融资与利率、最新 P/ARR；
- 数据口径圆标使用统一组件；
- 每个页签有独立来源状态，不再显示“飞书”徽标或“飞书源表”按钮；
- 桌面端保证对比图同屏可读；移动端允许卡片纵向排列和表格横向滚动；
- 图表 tooltip 包含点评和来源，不把解释只藏在表格尾列；
- 涨跌颜色同时配合箭头和正负号，不只依赖颜色。

## 11. 测试与验收

自动测试使用保存的官方页面夹具，不依赖实时网络，覆盖：

- 官方域名和重定向安全；
- schema v2 迁移与飞书字段移除；
- ARR 月环比和 P/ARR 历史匹配；
- OpenRouter 两个完整周的绝对/百分比环比；
- 最新模型代际筛选、币种和计费档位；
- 视频与 Coding Plan 缺失字段；
- 价格变更事件；
- 融资频率、票息和币种归一化；
- 官方模型卡可比性与未披露状态；
- AA 数据与官方 Benchmark 隔离；
- 单任务 Token 成本计算；
- 算力实例、区域和计费模式隔离；
- 单来源失败保留 last-good 并标记过期；
- API 刷新范围不再接受 `feishu`；
- 单元测试、API 测试、lint、生产构建和桌面/移动端页面检查通过。

真实数据验收逐条打开原始来源核对数值、单位、日期和口径。任何无法核对的值必须删除或标为不可用。

## 12. 分阶段交付

1. 来源治理与 schema v2，彻底移除飞书运行时依赖；
2. ARR/P/ARR 与 OpenRouter 周环比；
3. 最新模型、视频、Coding Plan 价格及涨降价事件；
4. 融资、债务和算力租赁；
5. 厂商官网模型卡 Benchmark；
6. AA Intelligence Index、单任务 Token 成本与整体页面验收。

每一阶段都必须生成可运行、可测试、可回退的看板切片，不能等全部数据源完成后一次性上线。
