 # Skill 信号规则与判断逻辑规范 (v9.30)

> **这是 Skill 的 single source of truth**。`analyze.py` 启动时 parse 本文件,
> 加载到 `SIGNALS` (pattern, score, label) 和 `LOGIC_TEMPLATES` (label -> 判断文字)。
> **改信号/改判断文字只动本文件**,Python 端无需触碰。
>
> 表格列: `label` | `score` | `pattern` | `judge`
> - `pattern` 单元格用 `;` 分隔多个备选 (避免与 markdown 表格的 `|` 冲突)
> - `judge` 单元格用 `;;` 分段 (按顺序拼接)
> - regex 元字符: `.` `*` `?` `+` `(` `)` `[` `]` `^` `$` 都按字面理解;**不要写 `\d` `\s` `\w`**

### v10.2 定增情景分类（2026-08-09 用户确认）

- 只对定增/非公开发行/向特定对象发行的**主预案**做一次评分；提示性公告、论证报告、可研、摊薄回报、审核意见等配套文件不重复计分。
- 程序读取预案 PDF，分解为募投结构、股本稀释、定价、认购方、锁定期与公告日60日股价位置，各因子分开加减分。
- 高景气主业明确扩产/产业化，且产业项目占募资 `>=50%`：与普通扩产统一按 `+7` 强利好。
- 募资用途采用互斥主分类：命中合格主业扩产后，低于50%的补流/普通还贷只作风险提示、不重复扣分；未命中合格扩产时，补流/普通还贷占比 `20%~<50%` 计 `-1`、`>=50%` 计 `-2`。只有文中明确为高息债且将降低财务费用时，才另计 `+2`。
- 发行上限占发行前股本 `>=30%`：`-5`；低于10%不因稀释单独加分，但不触发严重稀释。
- 固定发行价/公告日附近市价 `>=95%`：`+3`；`<=80%`：`-3`。询价发行仅披露“不低于20日均价80%”时，实际折价未知，不加不减。
- 明确内部人认购 `+3`；明确产业/战略投资者 `+2`；对象未定不加不减；明确纯财务投资且无产业/内部人绑定 `-1`。
- 公告日前60日前复权股价 `ratio_vs_avg>1.1` 或 `pos_60d>0.7`：`-2`；历史重跑必须使用公告日 as-of 取数，行情失败不扣分。
- PDF 无法读取或不足以可靠分解时，回退到「定增/可转债/配股」 `-2`，不猜测价格或投资者性质。

## 显示过滤规则 (v9.33.1) — 老板 6/16 拍

**铁律**: 老板只看 -7 ~ -10 分的强利空, 弱/中利空 (-1 ~ -6) 不在 PDF 展示; **Excel 仍展示全档位** (其余的所有内容都应该在 Excel 中)。

**v9.33 → v9.33.1 修订**:
- v9.33 初版: 在 analyze.py 出口处一刀切 (32 → 2), Excel 也跟着被砍
- v9.33.1 修订: analyze.py 输出全档位, **过滤只在 PDF 渲染层** (build_pdf._section_top5)
  - 影响: Excel 拿到 32 条全档位 (符合老板"其余的所有内容都应该在 Excel 中")
  - PDF 利空表 / 重大利空标的 概览行 / 风险回避段 三处都过滤到 ≤-7

**原因**:
- 弱/中利空是噪音 (董监高离职/异常波动/小额减持/监管问询 等), 频繁发生, 不构成方向性风险
- 老板复盘时只关心方向性强利空 (退市/立案/处罚/控股股东拍卖/业绩预亏), 信号强、决策价值高
- 弱/中利空 数量多, 显示会稀释强利空注意力

**实施 (v9.33.1, 4 模块联动)**:
- `analyze.py` 输出: `top_bad` / `all_bad_companies` / `bad_sectors` 保持全档位 (Excel 用)
- `analyze.py` `STRONG_BAD_DISPLAY_THRESHOLD = -7` 常量: 仅用于计算 `strong_bad_count` 计数 + 风险回避段 `top_bad_strong[:2]`
- `build_pdf._section_top5`: 当 `side=='bad'` 时, 渲染前 `items_pdf = [it for it in items if best_score <= -7]`
- `build_pdf._section_overview`: 概览"重大利空标的" 行也只列 ≤-7
- `sentiment.bad_count` = 全口径 32; `sentiment.strong_bad_count` = 强利空 2
- `score_distribution` 仍展示全档位分布
- 复盘 `recap.py` `top_bad` 来自 processed JSON = 全档位 31 (会进入 1.2 复盘段)
